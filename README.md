# Blackjack
A command-line blackjack game in Java, single player against a dealer. 
## How to Run
Requires Java 17 or later
```
git clone https://github.com/DylanB145/Blackjack.git
cd Blackjack/src
javac main.java
java main
```


## Features 
-  Betting
-  Doubling down
-  Card counting
-  Splitting
